# Importing Touch Grass

When a user asks to import or install this repository, do not copy its files into the user's current project. Register this repository as a plugin marketplace and install `touch-grass` at user scope when the host supports a non-interactive install. Desktop timing does not require hook trust; explain the optional hook review only when the user wants terminal or editor sessions counted too.

Read [IMPORT.md](./IMPORT.md) and use the section for the current host. Never enable optional hooks without the user's review. Touch Grass is local-only and must not be configured with network access.
