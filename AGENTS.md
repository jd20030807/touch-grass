# Importing Touch Grass

When a user asks to import or install this repository, do not copy its files into the user's current project. Register this repository as a plugin marketplace, install `touch-grass` at user scope when the host supports a non-interactive install, and explain any required hook trust step.

Read [IMPORT.md](./IMPORT.md) and use the section for the current host. Do not enable hooks without the user's review. Touch Grass is local-only and must not be configured with network access.
